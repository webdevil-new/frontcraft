# FrontCraft

Build beautiful frontend code with AI.

FrontCraft is an AI-powered toolkit that helps frontend developers generate production-ready UI components, convert HTML to React/Vue, improve accessibility, and accelerate development.

## ✨ Features

- AI React Component Generator
- AI Vue Component Generator
- Tailwind Generator
- Accessibility Checker
- HTML → React Converter
- Live Preview
- Copy to Clipboard
- Dark Mode

## 🛠 Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui
- Prisma
- PostgreSQL
- OpenAI API
- Vercel
